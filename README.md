# Product Analytics for Small Data (MVP)

Программный комплекс для анализа пользовательских траекторий в условиях дефицита данных. 
Репозиторий содержит аналитический код и эмпирическую базу к научной статье: *"Продуктовая аналитика малого продукта: как принимать решения в условиях ограниченных данных"*.

**Стек технологий:** SQL (PostgreSQL: оконные функции), Python (Pandas, NumPy, нечеткая логика).

**Структура проекта:**
* `data_cleaning.sql` — оконные функции для алгоритмической сессионизации и очистки структурного шума.
* `cleaned_mvp_sessions.csv` — нормализованный срез поведенческих данных электронной коммерции (на базе Olist).
* `markov_model.py` — расчет матрицы переходных вероятностей (цепи Маркова) с применением аддитивного сглаживания Лапласа для устранения эффекта нулевых частот.
* `fuzzy_logic.py` — классификация пользовательских сессий посредством алгоритмов нечетких деревьев решений (Fuzzy Decision Trees) и фаззификация вероятностей.
